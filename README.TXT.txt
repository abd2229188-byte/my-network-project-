My Network Project in Cisco Packet Tracer

What it does:
-  This network simulates a small organization connected using 3 routers.
- Uses VLANs, DHCP, NAT, and static routing
- All PCs can access each other and the internet

How to test:
1. Open "my_network_lab.pkt" in Cisco Packet Tracer
2. Try to ping between PCs
3. See configuration in router_config.txt, switch config.txt,device config.txt

DEVICE ROLE:-
 **R1 (Main Router):** Connects to the ISP and routes traffic to other routers.
- **R2 (Internal Router):** Handles routing between VLANs and local networks.
- **R3 (Branch Router):** Connects a remote branch to the main network.

FILES:
1.my_network_lab.pkt=main cisco lab
2.switch config.txt=switch configuration
