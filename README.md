# 💻 My Network Project in Cisco Packet Tracer

## 🧠 What it does
- Simulates an **organization network** with multiple routers and switches  
- Uses **VLANs, DHCP, NAT, and Static Routing**  
- All PCs can access each other and the Internet  
- Designed for learning and demonstrating basic network communication

---

## 🧪 How to Test
1. Open **`my_network_lab.pkt`** in Cisco Packet Tracer  
2. Use the **ping** command between PCs to test connectivity  
3. Check the configuration scripts:
   - `router_config.txt`
   - `switch_config.txt`
   - `device(pc,laptop)_config.txt`

---

## ⚙️ Application Needed
- **Cisco Packet Tracer**
